# Land Criativa - Landing Pages Profissionais

Este projeto é uma landing page completa para a **Land Criativa**, uma empresa especializada em criar páginas de alta conversão com design moderno, responsividade total e SEO otimizado.

## 🌐 Demonstração

Acesse: [https://landcriativa.com](https://landcriativa.com)

---

## 📁 Estrutura do Projeto

- `index.html` — Página principal do site.
- `projetos.html` — Portfólio com exemplos de projetos desenvolvidos.
- `sobre.html` — Seção sobre a empresa e seu processo de criação.
- `obrigado.html` — Página de agradecimento após envio de formulário.
- `styles.css` — Estilo principal com suporte a tema escuro/claro.
- `scripts.js` — JavaScript com funcionalidades como:
  - Preloader
  - Animações AOS
  - Filtro de projetos com Isotope
  - Alternância de tema claro/escuro
  - Chatbot interativo
  - Efeito de digitação e animações no scroll
- `.htaccess` — Arquivo de configuração para servidor Apache (ex: URLs amigáveis, redirecionamentos, segurança).

---

## 🚀 Tecnologias Utilizadas

- **HTML5** / **CSS3**
- **JavaScript Puro (ES6+)**
- **Bootstrap 5**
- **Font Awesome**
- **Google Fonts (Poppins, Fira Code)**
- **AOS.js** para animações ao rolar a página
- **Isotope.js** para filtro de projetos
- **.htaccess** para controle de headers e rotas (em ambientes Apache)

---

## ✨ Funcionalidades

- Layout 100% responsivo e mobile-first
- Design moderno com efeitos visuais e partículas
- Suporte a tema escuro automático com toggle
- Preloader animado
- Chatbot com respostas dinâmicas
- Filtros no portfólio com animações
- Scroll suave com animações contextuais
- Otimização para SEO e redes sociais (Open Graph, Twitter Card)
